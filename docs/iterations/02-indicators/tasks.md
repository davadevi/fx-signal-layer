# Итерация 02: Индикаторы
**Фаза 1 роадмапа — Неделя 1–2**  
*Источник: docs/research/fx-signal-methods.md, Фазы 1 и 3*

## Rule-based индикаторы (Фаза 1)

- [ ] **Перцентильный сигнал (основной):** флаг дней когда курс в нижнем 20-м перцентиле за trailing 30 дней — реализовать первым
- [ ] **RSI(14) < 35 (подтверждающий фильтр):** не самостоятельный сигнал, только в комбинации с перцентилем
- [ ] **Фильтр режима рынка:** подавлять сигналы когда 30-дневная реализованная волатильность выше 85-го перцентиля за год (Crisis-режим)
- [ ] **Reversal:** отскок от минимума — курс был на дне, пошёл вверх («окно закрывается»)
- [ ] **Seasonality:** календарный профиль + праздники стран-получателей
- [ ] **Momentum:** проверить — по ресёрчу скорее всего отрицательный результат (t-stat 1.417, незначимо), задокументировать

## Режимный детектор (Фаза 3, опционально)

- [ ] HMM 3-состоянийный (Calm / Normal / Crisis) на дневных log-return + волатильность
- [ ] Фильтр энтропии Шеннона: подавлять сигналы при энтропии вектора вероятностей HMM > 0.85
- [ ] Сравнить: перцентиль волатильности (простой) vs HMM (точнее) — что даёт лучший lift

## Для каждого индикатора

- [ ] Наследует `BaseIndicator`, вызывает `self._filter()` первым
- [ ] Unit-тест на no-lookahead
- [ ] Обрабатывает артефакты forward-fill (выходные не считаются как дни моментума)
- [ ] Запись результата бэктеста в `docs/iterations/02-indicators/log.md`
