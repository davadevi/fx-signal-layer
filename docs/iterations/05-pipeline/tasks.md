# Итерация 05: Нотификационный слой
**Фаза 4 роадмапа — Неделя 3–4**  
*Источник: docs/research/fx-signal-methods.md, Фаза 4 и Разделы 6–7*

## Шаблон текста уведомления

- [ ] Шаблон: «Курс RUB→[Валюта] вблизи [N]-дневного минимума (нижний [P]-й перцентиль). Текущий курс: X.XX. [CTA: Открыть]»
- [ ] Только факты о прошлом/настоящем — никаких предсказаний, никакой срочности
- [ ] Чеклист запрещённых формулировок: «вырастет», «успей», «лучший момент», «выгодно именно сейчас»
- [ ] Конкретные значения: перцентиль + текущий курс — без абстрактных «выгодных условий»

## Обработчик устаревшего курса

- [ ] Тот же день (курс ЦБ действителен весь рабочий день): показать подтверждённый текущий курс
- [ ] Следующий день: чёткое сообщение «Этот алерт был для курса [вчера]. Сегодняшний курс: X.XX»
- [ ] Если курс ухудшился с момента уведомления: баннер «Курс изменился. При отправке: X.XX. Текущий: X.XX»
- [ ] Никогда не скрывать факт изменения курса

## Частота и приоритизация

- [ ] Cooldown: минимум 72 часа между сигналами по одному коридору
- [ ] Время доставки по умолчанию: 8:00 по местному времени получателя
- [ ] Приоритизация при конкурирующих коридорах: побеждает коридор с наиболее сильным сигналом (глобальный лимит на клиента)
- [ ] Тихий период (если применимо по коридору) → не слать

## Комбинирование индикаторов

- [ ] Взвешенное голосование: перцентиль (основной) + RSI-фильтр + режим рынка
- [ ] Сигнал генерируется только при прохождении всех активных фильтров
- [ ] Логировать какой индикатор сработал — для SHAP-трейсабилити в пуше

## CLI и выходные артефакты

- [ ] `make signals DATE=2025-01-15` → таблица сигналов с обоснованием
- [ ] `python -m src.pipeline.run --cutoff-date DATE` — CLI
- [ ] Каждый сигнал содержит: коридор, перцентиль, RSI, режим, текст пуша — для аудита

## Критерий принятия

Финальный E2E тест: запустить `make signals DATE=<out-of-time date>` → получить корректный текст уведомления с правильным перцентилем и курсом, без запрещённых формулировок
