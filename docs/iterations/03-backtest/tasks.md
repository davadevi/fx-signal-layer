## Метрики

- [ ] `hit_rate@h` для h = 1/3/5/10/20 дней
- [ ] `lift_over_random`: base rate считается только по торговым дням (`is_trading_day == True`)
- [ ] Выгода момента: **только вперёд** (средний курс следующих h дней, не ±h симметрично)
- [ ] `signal_frequency`: сигналов на коридор в неделю — цель ≤2
- [ ] `clustering_score`: коэффициент вариации интервалов между сигналами
- [ ] Откалибровать частотный cap: ≤2 сигнала/коридор/неделю в среднем по бэктесту
