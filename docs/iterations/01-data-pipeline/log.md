## 2026-09-02 feat(data): implement CBR historical FX rate downloader

- **Commit:** `910b5e2`
- **Decision:** Использовать поле `VunitRate` из CBR XML вместо `Value / Nominal`
- **Why:** ЦБ меняет номинал без предупреждения (UZS был 1000, стал 10000 в 2024). `VunitRate` всегда нормализован к курсу за 1 единицу валюты — не нужно хранить номинал в коде.
- **Do not repeat:** Не брать `Value` напрямую и делить на жёстко зашитый номинал — сломается при очередном изменении номинала ЦБ.

- **Decision:** Один запрос на весь диапазон дат (2020–сегодня) вместо годовых чанков
- **Why:** API ЦБ без документированного лимита на диапазон; тест показал, что 6+ лет возвращаются за один запрос без ошибок.
- **Do not repeat:** Не добавлять chunking без причины — усложняет код, API справляется.

- **Decision:** Forward-fill + флаг `is_trading_day=False` вместо пропуска выходных строк
- **Why:** Индикаторам нужен непрерывный daily-индекс для rolling-вычислений (скользящее среднее, перцентиль). Флаг позволяет бэктесту исключать выходные из базовой частоты сигналов.
- **Do not repeat:** Не считать выходные как «дни моментума» — курс в субботу = курс пятницы, движения нет.

**Результат:** `data/processed/rates.parquet` — 19 496 строк, 8 коридоров, 1642 торговых дня на коридор, диапазон 2020-01-01 — 2026-09-02.
