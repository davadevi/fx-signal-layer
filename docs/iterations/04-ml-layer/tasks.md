# Итерация 04: ML Layer
**Фаза 2 роадмапа — Неделя 2–3**  
*Источник: docs/research/fx-signal-methods.md, Фаза 2*

## Разметка таргета

- [ ] Метка = 1 если день в нижнем 20-м перцентиле за 30 дней **И** следующие 5 дней показывают положительную доходность (курс получателя снизился = выгодно для клиента)
- [ ] Проверить баланс классов: «выгодный день» — миноритарный класс

## Feature Engineering (15–20 признаков)

- [ ] Из rule-индикаторов: перцентильный ранг, RSI, режим волатильности
- [ ] Лаговые курсы: rate_t-1, rate_t-3, rate_t-5
- [ ] Скользящая статистика: rolling mean, std, min за 7/14/30 дней
- [ ] Макро: USD/RUB изменение за 5 дней, дивергенция коридора от USD
- [ ] Сезонность: день недели, день месяца, месяц

## Модели

- [ ] **Baseline: логрег** с `class_weight='balanced'` — для sanity check и интерпретируемости
- [ ] **LightGBM** с `is_unbalance=True` — основная модель
- [ ] Walk-forward с эмбарго 5 дней; scaler/encoder fit только на train-слайсе, не на полном датасете
- [ ] Оценивать по precision-recall AUC, не по accuracy
- [ ] Порог решения — максимизировать lift при частоте ≤2 сигнала/неделю (не F1)

## SHAP интерпретируемость

- [ ] SHAP-анализ на каждом fold: подтвердить 2–3 доминирующих интерпретируемых признака
- [ ] Отклонить модель если топ SHAP-признаки неинтуитивны
- [ ] Каждый сигнал должен быть прослеживаем: «Курс в 12-м перцентиле за 30 дней, RSI=31, волатильность низкая»

## Критерий принятия

Если LightGBM lift превышает rule-based менее чем на **5 п.п.** — оставить rule-based (проще, объяснимее, устойчивее при ~700 обучающих днях)
