# Интерактивный прототип мобильного интерфейса

Mobile-first UI для сценария трансграничного перевода и наблюдений за курсом. Визуальный язык вдохновлён мобильным банкингом Альфа-Банка: чёрно-белая основа, красный акцент, крупная типографика и карточная навигация. Это не официальный интерфейс банка.

## Запуск

Из корня репозитория запустите локальный сервер:

```bash
python3 -m http.server 8000 --directory ui
```

После этого откройте `http://localhost:8000`. Главный экран также можно открыть
напрямую из `ui/index.html`, но для исторической демонстрации нужен локальный
сервер, чтобы браузер мог загрузить `timeline-data.json`.

## Что работает

- навигация между главной, платежами, историей и профилем;
- карточка валютного наблюдения без прогнозных формулировок;
- переключение AMD/KGS/KZT/TJS/UZS с перерисовкой графика;
- настройка уведомлений и тихих часов;
- расчёт суммы трансграничного перевода;
- подтверждение и экран успешной отправки;
- адаптация к мобильному экрану и клавиатурная навигация.

## Симулятор push-уведомлений

Отдельный интерактивный стенд доступен по адресу `http://localhost:8000/push-simulator.html`. Из основного прототипа в него можно перейти по колокольчику или карточке «Посмотреть push-уведомление» на главном экране, а также из раздела «Профиль».

Симулятор позволяет выбрать валюту и сценарий, проверить клиентский текст, тихие часы и лимит двух сообщений за семь дней. Доставленный пуш можно открыть: он ведёт на экран курса, откуда доступен переход к переводу.

## Демонстрация за период

Историческая демонстрация доступна по адресу `http://localhost:8000/timeline-demo.html`, с главного экрана приложения или из симулятора пушей.

Слева постепенно строится график выбранной валюты за произвольный период, справа синхронно обновляется телефон клиента. В момент отправки на графике появляется красный вертикальный маркер, на телефоне — push-уведомление, а событие добавляется в журнал. Можно менять валюту, даты и скорость, ставить воспроизведение на паузу, переходить по дням и перемещать ползунок времени.

Для демонстрации используется прозрачное shadow-правило: курс минимум на 1% ниже среднего за 30 публикаций и cooldown 7 календарных дней. Это визуальный сценарий, а не утверждение о готовности метода к запуску.

В репозитории уже лежит готовый `ui/timeline-data.json` с курсами на 02.09.2026.
Чтобы обновить его из нормализованных данных проекта, выполните:

```bash
python -m src.data.download
python ui/export_timeline_data.py
```

Экспортёр читает торговые дни из `data/processed/rates.parquet`. Для расчёта
перевода добавлена демонстрационная надбавка 1,2%; в реальном продукте вместо
неё должен использоваться актуальный курс приложения от поставщика ликвидности.
